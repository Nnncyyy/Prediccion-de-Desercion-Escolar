# Trabajo colaborativo GitHub

1. Clonar repositorio y ejecutar README.
2. Asignar una issue `RF_XX: descripción`, estimación y persona responsable.
3. Crear rama `feature/INT_03-ml-evaluacion` desde `main` actualizado.
4. Realizar commits pequeños con mensajes `feat(RF_09): agrega evaluación ML`.
5. Ejecutar `cd backend && pytest` / `cd frontend && npm run build`.
6. Crear Pull Request con capturas, casos de prueba y vínculos a RF/CU.
7. Revisar en pareja, resolver comentarios y fusionar.

No compartir información personal real ni subir .env; usar datos sintéticos para la demo.
